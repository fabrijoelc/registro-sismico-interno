Antes de importar

  1. Elige el catálogo correcto. Cada archivo tiene un encabezado diferente.
  2. Conserva los códigos como texto para no perder ceros iniciales, como 01.
  3. Revisa los campos obligatorios, estados y valores permitidos. Si una fila es inválida, se cancela toda la carga.
  4. Puedes volver a cargar un archivo: los códigos ya registrados se omiten.
